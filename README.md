# AI репозиторий для генерации UI изображений

Этот репозиторий используется как база знаний для AI Copilot, который создает новые варианты экранов приложения с интеграцией баннеров и виджетов.

Главный принцип:

**Сохранять исходный интерфейс и изменять только необходимые элементы.**

AI должен работать не как генератор нового дизайна, а как UI-инженер, который аккуратно внедряет новые компоненты в существующий экран.

## Структура

- `референсы` — примеры экранов других приложений и UI-паттерны.
- `компоненты` — баннеры, виджеты и элементы, которые можно добавлять.
- `экраны_пользователей` — исходные экраны для обработки.
- `правила` — инструкции для AI.
- `результаты` — созданные изображения.
