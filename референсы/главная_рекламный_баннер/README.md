# Главная страница — рекламный баннер

## Назначение

В этой папке хранятся референсы и примеры интеграции рекламного баннера на главную страницу приложения.

## Что должен изучать AI

AI анализирует:

- расположение рекламного блока;
- размеры баннера;
- отступы между элементами;
- поведение соседних компонентов;
- как освободить место без изменения интерфейса.

## Правила генерации

Можно:

- добавить рекламный баннер;
- аккуратно сдвинуть существующие блоки;
- адаптировать размер баннера под экран.

Нельзя:

- менять текст;
- менять навигацию;
- удалять существующие элементы;
- перерисовывать экран.

Результат должен выглядеть как настоящий экран приложения после добавления рекламного баннера.
