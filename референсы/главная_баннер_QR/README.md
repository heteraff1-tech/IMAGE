# Главная страница — баннер QR

## Назначение

В этой папке хранятся референсы замены существующего блока карты лояльности или QR-блока на главной странице.

## Что должен определить AI

AI должен найти:

- карту лояльности;
- QR-код;
- штрихкод;
- количество баллов;
- название карты;
- связанные элементы интерфейса.

## Правила замены

Можно:

- заменить старый QR или штрихкод;
- вставить новый баннер с собственным QR;
- сохранить структуру карточки.

Нельзя:

- удалять текст;
- удалять количество баллов;
- менять оформление карты;
- менять остальные элементы экрана.

Главная цель:

Новый QR-баннер должен выглядеть как изначальная часть приложения.
