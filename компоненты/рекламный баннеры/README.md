# Рекламные баннеры

В этой папке хранятся готовые изображения рекламных баннеров.

AI должен использовать эти изображения как готовые компоненты для интеграции в экраны приложения.

Правила:
- не изменять дизайн баннера;
- не перерисовывать баннер;
- использовать оригинальное изображение;
- аккуратно встроить его в существующий экран.
