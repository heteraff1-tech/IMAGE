# Компоненты

В этой папке хранятся готовые визуальные компоненты, которые AI Copilot может использовать при генерации новых экранов.

## Правила использования

- Каждый компонент хранится просто как изображение.
- Не нужно создавать дополнительные описания или JSON-файлы.
- AI должен анализировать изображение компонента самостоятельно.
- Компоненты нельзя изменять внутри себя.
- Компонент должен быть аккуратно встроен в существующий экран.

## Назначение папки

Здесь будут храниться элементы, которые нужно вставлять в существующие интерфейсы:

- баннеры;
- QR-блоки;
- виджеты;
- другие готовые UI-элементы.

AI должен использовать эти изображения как готовые строительные блоки, сохраняя их внешний вид.
