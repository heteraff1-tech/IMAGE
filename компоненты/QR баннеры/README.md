# QR баннеры

В этой папке хранятся готовые изображения баннеров с QR-кодом.

AI должен использовать их для замены существующих QR или штрихкодов в интерфейсе приложения.

Правила:
- не менять содержимое QR баннера;
- использовать готовое изображение;
- сохранять оригинальный UI вокруг заменяемого блока;
- не удалять текст, баллы, подписи или другие элементы карточки;
- менять только область QR/баннера.
